# 0008：以百灵鸟作为对标清单，不作为许可授权来源

- 状态：接受
- 日期：2026-08-14

## 决策

固定百灵鸟 `echobird/codex-plugins` 的提交并逐项生成对标表，用它发现插件名称、类别、形态和声明上游。对标条目只进入研究清单，不因出现在百灵鸟市场而自动进入暴喵公开市场。

## 原因

百灵鸟默认市场聚合 180 个插件，其中大量插件声明来自 `openai/plugins`，另有多个第三方仓库；仓库根目录没有覆盖全部内容的统一许可证。插件 manifest 中的许可证字段是线索，不等同于完整的再分发证据。

## 执行

- 有包内许可文件、声明为允许再分发且没有脚本的条目优先进入候选。
- 缺许可证证据、含脚本或与现有同名插件来源不同的条目单独复核。
- `Proprietary`、`UNLICENSED`、许可证缺失或专用条款默认暂不接入。
- 同步脚本不得从对标表自动复制或发布第三方插件。
