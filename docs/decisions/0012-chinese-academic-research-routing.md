# 0012：中文学术能力采用“官方数据源 + 暴喵方法工具箱”

日期：2026-09-16

## 决策

论文数据库、引用网络和云端知识库能力走 Codex 官方插件目录；暴喵精选只打包许可明确、固定提交、无脚本的学术方法 Skills。首页用中文把两者放在同一研究入口中，但继续分开标源和计数。

## 原因

数据源插件通常需要账号连接、服务端 API 和持续更新，复制包会破坏来源、认证与可用性判断。方法型 Skills 可以在不接触凭证的情况下帮助用户精读、综合、写作和评审，适合固定版本审核与离线安装。

## 结果

- 用户搜索“论文、文献、引文、综述、科研”等中文词即可发现两类能力。
- 暴喵新增一个插件而不是拆成十张卡片，避免虚增数量。
- 官方插件是否可用仍由本机 Codex 决定；暴喵不承诺账号范围。
- 含脚本的文献检索仓库继续留在候选审查范围，不因功能热门而降低门禁。
