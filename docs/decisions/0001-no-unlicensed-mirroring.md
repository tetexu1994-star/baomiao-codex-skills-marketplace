# ADR-0001：不镜像无明确许可的 Skill

- 状态：已采纳
- 日期：2026-08-13

## 决策

MVP 只发布固定到 40 位提交哈希的来源索引，不复制上游 Skill 内容。只有当 Skill 目录本身或仓库具有可核验的再分发许可，并通过人工审核后，未来版本才可以选择性镜像。

## 原因

公开可读、可 clone 不等于拥有再分发许可。参考仓库根目录没有 LICENSE，条目又没有上游来源和许可证字段，无法证明其中内容可以再次分发。索引原始来源能保留作者身份、降低供应链分叉，并让客户端直接通过加速线路访问官方或原始来源。

## 后果

- 市场不会以“收录数量”牺牲许可证和安全门槛。
- 来源失效时，客户端不会自动改用不明镜像。
- 用户安装前始终能看到发布者、仓库、固定版本、许可证和能力风险。
