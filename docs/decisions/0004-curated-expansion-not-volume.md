# 0004：扩容以许可与权限门槛为上限

- 状态：被 0005 部分取代（来源、许可与可执行文件门槛仍有效）
- 日期：2026-08-13

## 决策

市场可以持续扩充来源，但只有同时满足“固定原始来源、许可覆盖完整 Skill 目录、无可执行安装内容、权限不属于 blocked、完整文件扫描、人工审核”的条目进入 approved。`high` 条目自 0005 起可进入增强权限层，但必须增加独立确认。

官方发布者身份只提高来源可追溯性，不自动降低权限等级。社区聚合页仅用于发现原始仓库，不作为下载、许可证或发布者证据。

## 影响

目录数量增长会慢于全网 Skill 总量，但每次扩容都有可复跑候选、文件摘要、审核证据和明确的暂缓理由。Windows 适配条目若会更改系统配置、要求管理员权限或关闭沙箱，也必须保持暂缓，不能因目标用户匹配而例外。
