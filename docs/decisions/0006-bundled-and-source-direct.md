# 0006：市场同时支持审核包与官方源码直装

- 状态：接受
- 日期：2026-08-13

## 决策

目录支持两种交付方式：

1. `copy-source-directory`：市场仓库保存与候选摘要逐字节一致的 Codex 插件包，可由 Codex marketplace 直接发现。
2. `source-direct`：市场仓库只保存中文元数据、固定提交、上游链接、许可证证据、文件摘要和审核记录；暴喵客户端从原始仓库固定提交下载。

## 原因

单纯复制第三方内容会同时放大许可证、归属、仓库体积和供应链风险。只做少量打包又无法形成有用的市场规模。双交付模式让明确适合再分发的 Skill 保持即装即用，同时允许具名官方来源在不复制正文的前提下扩大目录。

## 门禁

- 两种模式都必须固定 40 位提交、保留原始来源和许可证、生成候选摘要、通过人工审核。
- `source-direct` 不进入 `.agents/plugins/marketplace.json`，避免伪装成本仓库原创插件。
- 客户端只能从条目声明的原始仓库下载；不得通过不透明代理改写内容或身份。
- 上游包含可执行文件或静态扫描阻断项时，不能因为采用源码直装而绕过审核。
