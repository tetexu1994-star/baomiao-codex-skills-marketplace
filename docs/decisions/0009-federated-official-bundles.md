# 0009：官方合集按一个插件发布

- 状态：采纳
- 日期：2026-08-14

## 决定

当上游本身把大量同一产品族的 Skills 作为一个 Codex marketplace 插件发布时，暴喵保持这个产品边界。Azure 的 202 个 Skills 作为一个 `azure-agent-skills` 插件；NVIDIA 当前只发布官方 Skill Finder；AWS 按上游产品插件分组，但只打包通过无可执行文件门禁的 Skill 子树。

## 理由

把每个 Skill 拆成一张市场卡片会制造虚假的插件数量、降低检索质量，并让用户在导入市场后面对数百个近似选项。一个插件可以合法地承载多个 Skills；市场首页应展示用户需要选择的产品单元，而不是内部文件数。

## 影响

- 市场从 72 增到 77 个插件，插件内实际 Skill 总数为 278；
- 上游插件中的 MCP、hooks、脚本不会随 Skill-only wrapper 一同发布；
- 首页卡片需要展示“包含 N 个 Skills”，让用户看见实际能力规模；
- 同步仍只生成候选，只有明确列入人工批准表的固定提交才可打包。
