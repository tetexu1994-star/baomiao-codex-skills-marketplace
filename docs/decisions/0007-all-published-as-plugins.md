# 0007：公开目录统一发布为 Codex 插件

- 状态：接受
- 日期：2026-08-14
- 取代：0006 的双交付模式

## 决策

公开目录中的 72 个条目全部封装为 Codex 插件并进入 `.agents/plugins/marketplace.json`。每个插件保留原发布者、原始仓库、固定提交与许可证；插件内的 Skill 文件必须与已审核候选摘要一致。仓库级许可证复制到对应 Skill 目录并纳入公开完整性清单。

## 原因

产品定位是“插件市场”。只展示一部分插件、另一部分原始 Skill 直装，会让用户难以判断能否从同一个市场完成安装，也使客户端需要维护两套路径。Harness 上游采用 Apache-2.0，固定提交中的 52 个入选目录没有可执行脚本，允许在保留归属与许可证的前提下合规封装。

## 边界

- 插件化不改变上游作者身份，不把第三方内容标为暴喵原创。
- 首页直接展示插件目录，不把内部审核标准作为面向普通用户的主要内容。
- 原始来源、许可证和权限仍在每张插件卡片中可查看。
- 同步管线仍只生成候选；自动同步不会自动写入公开插件市场。
- `source-direct` 继续保留为 schema 的兼容能力，但当前公开目录不使用。
