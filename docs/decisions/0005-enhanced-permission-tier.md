# 0005：新增增强权限层，不放宽来源与许可底线

- 状态：接受
- 日期：2026-08-13

## 决策

允许发布 `risk.level: high` 的 Skill，以覆盖 OAuth、联网、外部写入、浏览器控制、本机命令和系统配置等实用场景。高权限条目必须明确列出能力，并在普通安装确认之外执行 `confirm-enhanced-permissions`。

继续拒绝许可证不清、固定来源不可核验、目录含可执行文件、pipe-to-shell、凭证窃取、混淆命令或来源伪装。安装 Skill 不等于授权其未来全部操作；凭证仍由第三方官方 OAuth 或用户本机环境管理。

## 影响

市场可以覆盖部署、项目管理、知识库、浏览器自动化和 Windows 环境配置等常见需求，同时让客户端对高权限条目采用更强的展示和确认门禁。旧客户端若不认识增强权限能力，应阻断安装。
