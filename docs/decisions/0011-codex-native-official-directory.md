# 0011：官方插件走 Codex 原生目录，不镜像归档仓库

日期：2026-08-17

## 决定

暴喵市场继续发布 77 个经过固定提交、许可证和文件摘要审核的插件包；OpenAI 官方插件不复制进本仓库，而是作为独立的 `codex-native` 联邦来源展示。客户端通过用户本机可信的 `codex.exe` 执行只读参数数组 `plugin list --available --json`，由 Codex 根据当前版本、产品和账号返回可用插件。

`https://github.com/openai/plugins` 仅保留为历史来源证据。该仓库已于 2026-08-16 被 OpenAI 归档，不得作为安装回退、持续同步源或暴喵镜像依据。

## 原因

- Codex 官方目录已经迁移为原生远程目录，`openai-curated-remote` 等名称和内容由 Codex 管理；
- 官方插件可能使用专有条款、第三方 App、MCP 或账号认证，公开仓库中的 manifest 不能替代完整再分发许可；
- 写死历史“180 个”会在官方目录更新或按账号过滤时误导用户；
- 让本机 Codex 返回目录，可以保留官方身份、认证边界和产品可用性判断。

## 结果

- 页面明确区分“暴喵精选”和“Codex 官方插件目录”；
- 暴喵精选仍可一键加入，官方目录只提供查看命令与 OpenAI 文档入口；
- 官方目录数量不进入暴喵总数，也不生成本地插件卡片；
- 官方来源描述经过独立 Schema 和 SHA-256 校验，但它不是插件安全审核；
- 官方目录不可用时只提示用户在 Codex Plugins 页面查看，不回退到归档仓库。
